## 追加：自定义外接模型（接入配置）
- 新增 `assistant-llm.js`：左侧「接入配置」面板 + 四种协议适配（ADP/LKE SSE、Coze Bot SSE、火山方舟、通用 OpenAI 兼容）。
- 配置只存 localStorage `genshin_llm_cfg_v1`，字段精简为 `{provider, key, base, model}`（旧版 appKey/apiKey 会自动迁移）。
- 请求时把站内 `handoffText()` 压缩成「站内档案」system 上下文，保证材料/面板数字不被模型改写；未配置或请求失败自动回退本地知识引擎，并给出 sys 提示。
- `assistant.js` 增加 `startLLM / beginLLM / runLocal / md()`，流式渲染为 `.llm-card`，支持复制全部与一键转交；对外钩子 `window.TwinAgentNotice / TwinAgentReset`。
- 联调用 `_build/_mock_llm.py` + `_build/_cdp_check.js`（本地 mock 三种 SSE 协议，CDP 真实等待，避免 headless 虚拟时钟触发 90s 超时）。

## 追加：默认接扣子（双 Bot）
- 出厂默认改成 `provider: coze`，密钥预填在 `assistant-llm.js` 的 `DEFAULT_CFG`，地址 `https://api.coze.cn`；壹号档案 Bot `7698303099848835113`、贰号配队 Bot `7698305675894079507`。
- 配置结构扩展为 `{provider, key, base, model, models:{archive,team}}`；coze 用 `models[agent]`，其他协议仍用 `model`。
- 面板切到 coze 时模型框标题变成「Bot ID · 壹号档案 / 贰号配队」，切换智能体自动换值（`window.TwinLLMSetAgent`，assistant.js 的 switchAgent 里调用）。
- 新增 `withContext()`：ADP / 扣子只吃一条 user 文本，把 `buildContext()` 的站内档案拼到消息前面（格式「【站内档案】…用户问题：…」），否则扣子 Bot 会答「暂无该角色档案」。真机联调：壹号雷电将军材料、贰号胡桃配队均正常流式返回。
- 「清除本地配置与记录」写入空配置并持久化，不会被默认值回填；清空密钥后自动回退本地引擎。
- 联调脚本 `_build/_cdp_llm.js`（默认值/Bot 切换/真实流式，CDP 真实等待）。
